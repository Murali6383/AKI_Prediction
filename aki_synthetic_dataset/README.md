# Synthetic AKI Dataset

5,000 simulated patients with observations every 6 hours for 7 days.

Files: aki_synthetic_longitudinal.csv, synthetic_patient_summary.csv, dataset_summary.json.

This is artificial data for pipeline development only. It is not real patient data or clinically validated. Never report its metrics as real clinical performance. Split by patient_id. Exclude onset time, follow-up, IDs, timestamps and target columns from predictors.
